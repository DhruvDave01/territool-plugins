# TerriTool

One plugin for individual field sales reps and managers. Version 1.0.4.

Use the field-sales skill for your own accounts, leads, routes and visits. Use the managers skill for team assignments, rep routes and performance. The authenticated TerriTool account and server permissions determine access; installing both skills does not grant a manager role.

The plugin uses one MCP connection at https://app.territool.com/ai/mcp. Configure OAuth in OpenAI Platform using your existing TerriTool setup. No credentials are included.

Upload territool.zip as the unified plugin. Existing role plugins remain separate until you choose how to migrate them. This package does not change installed plugins or submit a public release.

Review cases cover both roles. The user-supplied demo plays and is shared for anyone with the link. Observed sections demonstrate field-sales behavior; manager coverage remains unverified. Before submission, verify coverage of both workflows, complete reviewer information and MCP configuration, and run the role-specific cases. Live behavior has not been tested by this build.
